# Docuvate SDKs

Official clients for the **headless** `/v1` product API. The contract is **autogenerated from NestJS** (`@nestjs/swagger` + DTO plugin) and exported to [`openapi/docuvate.v1.json`](../openapi/docuvate.v1.json). The same document is served at runtime from `GET /v1/openapi.json`.

| SDK | Package | API version |
| --- | --- | --- |
| Node (TypeScript) | `@docuvate/sdk` | 1.0.0 |
| Flutter (Dart) | `docuvate` | 1.0.0 |

## Regenerate (required after API changes)

```bash
pnpm openapi:export          # NestJS → openapi/docuvate.v1.json
pnpm sdk:codegen             # Node (@hey-api/openapi-ts) + Flutter (dart-dio)
pnpm sdk:check               # CI: fails on drift
```

## Node / TypeScript

```typescript
import { DocuvateClient } from '@docuvate/sdk';

const client = new DocuvateClient({
  baseUrl: 'https://your-host/v1',
  apiKey: process.env.DOCUVATE_API_KEY,
});

// Every operationId from the spec:
const list = await client.api.listDocuments({ query: { status: 'ready' } });
const tag = await client.api.createTag({ body: { name: 'Inbox' } });
```

See [`packages/sdk-node/README.md`](../packages/sdk-node/README.md).

## Flutter / Dart

```dart
final client = DocuvateClient(
  DocuvateClientConfig(
    baseUrl: 'https://your-host/v1',
    apiKey: apiKey,
  ),
);
final docs = await client.documents.listDocuments(status: 'ready');
final tags = await client.taxonomy.listTags();
```

Generated APIs: `meta`, `documents`, `taxonomy`, `organizer`, `settings`, `connectors`, `ml`.

Example CLI: `dart run example/bin/example.dart --api-key=...`
