# Model-gates fixtures

## Chat (`chat_extractive_cases.json`)

- **Provenance:** Seeded synthetic German business documents generated by `generate_chat_extractive_cases.py` (seed `20261011`).
- **Licence:** Docuvate CE fixture data; no personal data, no third-party corpora.
- **Regenerate:** `python bench/model_gates/fixtures/generate_chat_extractive_cases.py` (from repo root with worker venv + `PYTHONPATH`).
- Questions use paraphrases; unanswerables mix on-topic missing facts (shared vocabulary) and off-topic items that fail the retrieval score threshold on short docs.

## Classification (`classification_texts.json`)

- **Provenance:** Seeded overlapping German document blurbs from `generate_classification_fixtures.py` (seed `20261012`).
- **Licence:** Same as above (synthetic, licence-clean).
- **Embeddings:** Gate uses production `fastembed` via `embed_passages` at runtime.
